# vue-custom-CLI
A custom CLI for generating Vue.js projects with configurable templates and optional features.

## Features

During project creation, you can choose which technologies to include:

### Core
- TypeScript
- Vue Router
- Pinia
- Tailwind CSS
- Vuetify

### Utilities
- Axios
- VueUse
- Day.js
- Zod
- Vue I18n
- Pinia Plugin Persisted State
- Dotenv (.env support)

### Icons
- Font Awesome
- Flaticon UIcons

### Development
- Vue DevTools
- ESLint
- Prettier

### Testing
- Vitest
- End-to-End Testing
