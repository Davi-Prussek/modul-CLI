# Bem-vindo ao Modul CLI

Este projeto foi criado utilizando o **Modul CLI**, uma ferramenta de automação para criação de aplicações Vue. 
Ele oferece uma configuração inicial personalizada, adicionando estruturas, comandos e ferramentas que ajudam a iniciar projetos de forma mais organizada e produtiva.

Lembre-se que ele instala as dependências selecionadas na hora da criação da aplicação de forma automática.

## O que o Modul adiciona?

### Comandos personalizados

- Criação rápida de projetos Vue configurados.
- Geração de componentes, páginas e seções padronizadas.
- Automação de instalação e configuração de dependências.
- Fluxo interativo para escolher tecnologias e recursos.

### Estrutura organizada

- Arquitetura inicial baseada em boas práticas.
- Separação de componentes, páginas, serviços e configurações.
- Organização preparada para projetos escaláveis.
- Templates personalizados para acelerar o desenvolvimento.

### Pacotes e ferramentas integradas

- Configuração automática das principais bibliotecas escolhidas.
- Suporte para ferramentas de desenvolvimento modernas.
- Integração com recursos como:
  - TypeScript
  - Vue Router
  - Pinia
  - Tailwind CSS
  - Bootstrap
  - Vuetify 
  - Vuetify/v0 
  - Axios
  - VueUse
  - Zod
  - dayjs
  - ESLint
  - Prettier
  - Vitest
  - Playwright
